    • ตลาดทั้งหมดลงแรง (BTC −30% จากตอนซื้อ) → เติมเพชรหลัก ZAMA/NMR/SAFE
  • ขาย: ทุกเหรียญขาย 25% ที่ ×3, 25% ที่ ×10, 25% ที่ ×30, เก็บ 25% สุดท้าย — ตารางราคา + MC ที่ต้องถึงอยู่ในการ์ดแต่ละตัว.
  • ขายทิ้งทันทีถ้าเจ้าของเปลี่ยน (founder ออก, ขายเหรียญตัวเองหนัก, pivot ทิ้ง product, โกหกตัวเลข) — นี่คือเหตุผลเดียวที่เราซื้อ ถ้ามันหายไปก็ไม่มีเหตุผลถือ ไม่ว่าราคาจะเป็นเท่าไร.
  • ไม่ใช้ leverage. ไม่มีเหรียญไหนเกิน 20% ของพอร์ต.

วิธีคิด และข้อจำกัด

1) ตรวจ “คน” ก่อน “เหรียญ”. ทุกโปรเจกต์ให้คะแนนเจ้าของ 3 ด้าน 1–10 โดยต้องมีหลักฐานที่มีลิงก์:

  • ฉลาด (S) — paper ที่ตีพิมพ์/ถูกอ้างอิง, โค้ดที่เขียนเองบน GitHub, ของที่สร้างแล้วคนใช้จริง, ตำแหน่งที่ต้องแข่งเข้า (ไม่นับ “ex-Google” ลอย ๆ ถ้าไม่มีผลงาน)
  • ศีลธรรม (E) — เคยทิ้งเหรียญเก่าไหม, ทวีตปั่นราคา/สัญญาราคาไหม, unlock เอื้อ insider ไหม, เปลี่ยนกติกา airdrop ไหม, ตอนโดน hack ชดเชยผู้ใช้ไหม, เปิดเผยข้อมูลเร็วไหม, มีคดี/ข้อกล่าวหาไหม
  • วิสัยทัศน์ (V) — คิดเรื่องเดียวมานานหลายปีและสร้างออกมาจริง (ไม่ใช่เปลี่ยน narrative ตามตลาด: AI → DePIN → RWA)

2) เพชร = ผ่านทั้ง 3 ด้าน + ไม่มี red flag ร้ายแรง + token มีเหตุผลให้มีมูลค่า. เจ้าของเก่งแต่ศีลธรรมไม่ผ่าน → ตัด (เช่น PUBLIC, CYS, ZKJ). เจ้าของดีแต่ token มีเงื่อนไขที่ต้องรอ (unlock ใหญ่ใกล้มา, ยังไม่มี value capture) → “น่าจับตา”.

3) ข้อมูลที่ใช้: GitHub API (commit 90 วัน, ผู้ commit), Google Scholar / dblp / arXiv / IACR ePrint, เว็บ/เอกสารทางการ, Tokenomist / docs (unlock), DefiLlama (TVL/fees/revenue), CoinGecko (ราคา/MC/FDV ณ 1 ต.ค. 2026), ข่าว/โพสต์ต้นทาง (The Block, CoinDesk, Cointelegraph, forum ของ DAO). รูปเจ้าของเป็นรูปจริงจาก GitHub avatar / หน้าทีม / งานสัมมนา — ถ้าหารูปจริงไม่ได้เขียนว่า “ไม่มีรูปจริงที่ยืนยันได้” (ไม่ใช้รูปการ์ตูน/identicon).

4) ข้อจำกัด (สำคัญ):

  • เจ้าของดี ≠ ราคาขึ้น. โปรเจกต์ที่เจ้าของเก่งที่สุดหลายตัวในรายการนี้ราคาลง 90%+ จาก ATH เพราะ supply/unlock/ตลาด.
  • “1000 เท่า” จาก MC ปัจจุบัน แปลว่า MC ต้องไปถึงหลักหมื่นล้าน–แสนล้านดอลลาร์ ซึ่งแทบไม่เกิดกับเหรียญ infra. เป้าที่สมจริงในรอบหน้าสำหรับเหรียญที่ดีจริงคือ ×3–×30 — ตารางเป้าขายแสดง MC ที่ต้องถึงทุกขั้นให้เห็นเอง.
  • Binance Alpha สภาพคล่องต่ำ: ซื้อ/ขายหลักแสนบาทอาจมี slippage — แบ่งซื้อหลายไม้.
  • คะแนน S/E/V เป็นการตัดสินจากหลักฐานที่หาได้ภายในวันเดียว อาจพลาดข้อมูลที่ไม่เป็นสาธารณะ. รายละเอียดบางส่วนเป็นภาษาอังกฤษตามต้นฉบับ.
  • ไม่มี BTC / meme ตามโจทย์. หน้านี้ไม่ใช่คำแนะนำการลงทุน — ทุกบรรทัดมีลิงก์ให้ตรวจซ้ำก่อนใช้เงินจริง.
